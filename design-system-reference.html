Lucilla Aurelius Launchpad

L.A.L. — Design System

Chrome Hearts × teenage engineering, cast in bronze instead of silver: gothic blackletter on a matte-black hardware chassis, surfaced in cast bronze, bone/marble ivory, and dark oxblood glass.

Typography

Lucilla
UnifrakturMaguntia — wordmark, ABCD slot letters. Sizes: wordmark clamp(22–35px), ABCD letters pad-size × 0.7. The one indulgence: the only text on the chassis that isn't the plain mono/blackletter-label grid.
Tempo
Eagle Lake — buttons, knobs, pad names, fader, tagline. min(8.5px, pad-size × 0.2053) — nominally 8.5px, scales down only below the mobile pad-size floor.
Filter
Pirata One — LCD icon-grid screen labels only (FILTER, DELAY, TEMPO, ERASE, CORRECT, SHIFT, TIME, PUMP, OUT). A third blackletter voice, reserved for the screen.
128
JetBrains Mono — LCD digit readout (clamp(20–33px), weight 800) and the base UI font everywhere else.

Color

The --chrome-* token names are legacy from an earlier silver palette — their actual values are warm bronze/gold now, not chrome. Kept as-is rather than renamed, to avoid touching every rule that references them.

Spacing & Radius

Base unit--pad-size: clamp(41.4–57.6px) — desktop range; shrinks further below that via a width-aware formula so mobile still fits. --pad-gap: pad-size / 2.
Grid logicButtons/knobs/pads are 1 square · fader ≈ 2 squares + a gap · SHIFT/FX are half a square. Nearly every other dimension (icon-grid squares, label widths, font sizes) is a calc() off this one variable.
Chassis — 6px
Buttons/pads/chips — 2px
Knobs/LEDs — 50%
Grille — 0/6px/0/0

States

EngagedSteady on — red edge-ring glow only, no fill/LED
FlashOn press — momentary red bottom-bloom, fades 0.25s
Two-tier buttonsREC/ERASE, RPT/LATCH, TIME/CORR — interaction scoped to the top chip only; bottom chip is a non-clickable print
SHIFTPhysically depresses when engaged, not just a glow
KnobsEndless rotation, decoupled from the clamped value range

Motion

No boot/entrance animation currently — the machine renders instantly at full opacity. Several approaches (whole-machine blur/fade, a melting bronze-shell cover, per-control stagger) were tried and pulled back out. If revisited: keep it to a single animation on #instrument, not per-control staggering — that read as "chunky" in practice.
